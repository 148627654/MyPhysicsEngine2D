# V2-Day 12: 持续碰撞检测 (CCD) 之 撞击时间 (TOI - Time of Impact)

## 1. 目标
1.  **实现 TOI 计算核心**：在宽相锁定的“嫌疑对”基础上，精确计算两个物体在 $[t, t+dt]$ 时间段内发生碰撞的确切比例 $\alpha \in [0, 1]$。
2.  **数值求根算法**：利用二分法 (Bisection) 或 割线法 (Secant Method) 在连续运动路径上寻找距离为 0 的点。
3.  **支持旋转路径**：初步考虑平移与旋转叠加后的位姿插值。
4.  **数据挂载**：将计算出的 TOI 存储在 `Contact` 对象中，为明天的子步解算 (Sub-stepping) 提供依据。

---

## 2. 核心概念

### A. 什么是 TOI？
*   **Time of Impact** 是一个标量。如果 $\alpha = 0.5$，意味着碰撞发生在当前帧经过一半的时间点。
*   **数学本质**：寻找函数 $f(\alpha) = \text{Distance}(BodyA(\alpha), BodyB(\alpha))$ 的根，使得 $f(\alpha) = \text{Tolerance}$。

### B. 保守性进步 (Conservative Advancement)
这是解决 TOI 最稳定的算法。
*   **原理**：计算当前最近距离 $d$，基于当前速度，物体至少需要移动 $\Delta t = d / V_{rel}$ 才能相撞。不断“小步快跑”，直到距离小于一个极小的阈值。

---

## 3. 必须实现的技术清单

### A. 位姿插值函数 (Pose Interpolation)
- [ ] **`Transform Body::GetTransform(float alpha)`**：给定时间比例 $\alpha$，返回插值后的位置和角度变换矩阵。

### B. TOI 求根核心 (`TimeOfImpact` 类)
- [ ] **分离轴投影函数**：在给定 $\alpha$ 下，计算两个形状沿法线的投影距离。
- [ ] **求根循环**：
    1. 初始化 $\alpha = 0$。
    2. 计算当前位姿下的最近距离 $d$。
    3. 如果 $d < \text{target}$，返回 $\alpha$。
    4. 计算最大安全位移步长 $\Delta \alpha$。
    5. $\alpha = \alpha + \Delta \alpha$。
    6. 重复直到 $\alpha > 1$ 或达到最大迭代次数。

### C. `Contact` 类扩展
- [ ] **成员变量**：增加 `float m_toi`。
- [ ] **计算触发**：如果其中一个物体是 `Bullet` 且宽相重叠，执行 `ComputeTOI()`。

---

## 4. 技术实现细节 (Tips)

### 1. 终止条件 (Tolerance)
不要寻找 $d=0$，而要寻找 $d = \text{slop}$ (比如 0.002)。这样可以确保物体在碰撞瞬间保持微小间距，防止解算器因为深度穿透而产生数值爆炸。

### 2. 相对速度上限
在计算步长 $\Delta \alpha$ 时，如果相对速度几乎为 0，应立即跳出循环，防止除以 0。

### 3. 简单的线性简化
初次实现时，可以暂时**忽略旋转**对 TOI 的影响，仅基于位置线性插值。这能降低 70% 的数学难度，且能解决大部分穿墙问题。等到稳定性达标后，再加入旋转贡献项。

1.  **正碰 TOI 验证**：
    *   物体 A 在 $X=-5$，速度 $100$。墙在 $X=0$。$dt=1/60$。
    *   子弹一帧走 $1.666m$。预期碰撞发生在第 3 帧左右。
    *   **预期**：`ComputeTOI` 返回一个精确的 $\alpha$（如 0.85），验证该 $\alpha$ 下物体 A 边缘是否正好贴在墙上。

    *   两个紧贴但不动的物体。
    *   **预期**：TOI 逻辑不应被触发或返回 1.0。
