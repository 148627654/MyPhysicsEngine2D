# V2-Day 5: 空间查询与宽相集成 (Query & Broadphase)

## 1. 目标
利用动态 AABB 树实现高效的碰撞对过滤。
1.  **实现 `Query` 接口**：在 $O(\log N)$ 时间内检索出与指定区域重叠的所有物体。
2.  **构建 `BroadPhase` 类**：作为物理世界的“预筛选器”，管理动态树并维护“潜在碰撞对”。
3.  **消除 $O(N^2)$**：将碰撞检测的第一步从暴力遍历进化为基于空间的快速检索。

---

## 2. 核心概念

### A. 树查询 (Tree Query)
*   **深度优先搜索 (DFS)**：从根节点开始，如果当前节点的 AABB 与目标 AABB 重叠：
    *   如果是叶子节点，则记录结果。
    *   如果是内部节点，则递归检查其两个子节点。
*   **性能**：由于树是平衡的，查询时间复杂度为 $O(\log N)$。

### B. 宽相 (Broad-Phase) 与 窄相 (Narrow-Phase)
*   **宽相**：利用 AABB 快速排除绝对不可能碰撞的物体，产出“候选对”。
*   **窄相**：对候选对进行精确的形状检测（如昨天提到的 GJK/SAT）。
*   **今天我们的任务是完成高性能的宽相系统。**

## 3. 必须实现的技术清单

### A. `DynamicTree::Query` 函数
- [ ] **接口设计**：`void Query(const AABB& aabb, std::function<bool(int32_t)> callback)`。
- [ ] **非递归遍历**：使用手动栈（数组）模拟递归，避免频繁的函数调用开销。
- [ ] **回调机制**：每找到一个重叠的叶子，调用一次回调函数。

### B. `BroadPhase` 类的搭建
- [ ] **成员变量**：
    *   `DynamicTree m_tree;`
    *   `int32_t* m_moveBuffer;` (存储本帧移动过的物体索引)。
    *   `std::vector<Pair> m_pairBuffer;` (存储发现的潜在碰撞对)。
- [ ] **核心接口**：
    *   `int32_t CreateProxy(aabb, userData)`: 在树中创建物体并标记为“已移动”。
    *   `void MoveProxy(proxyId, aabb, displacement)`: 物体移动时，加入 `m_moveBuffer`。
    *   `void UpdatePairs(Callback callback)`: **最核心函数**。遍历 `m_moveBuffer`，针对每个移动过的物体去树中 `Query` 它的邻居，生成碰撞对。

## 4. 技术实现细节 (Tips)

### 1. 如何高效执行 `Query`
使用一个固定大小的栈（比如 `int32_t stack[256]`）来代替递归。256 的深度足以处理 $2^{256}$ 个节点的树，永远不会溢出。

```cpp
void DynamicTree::Query(const AABB& queryAABB, std::function<bool(int32_t)> callback) {
    int32_t stack[256];
    int32_t stackCount = 0;
    stack[stackCount++] = m_root;

    while (stackCount > 0) {
        int32_t nodeId = stack[--stackCount];
        if (nodeId == -1) continue;

        const Node& node = m_nodes[nodeId];
        if (AABB::Overlap(node.aabb, queryAABB)) {
            if (node.isLeaf()) {
                bool proceed = callback(nodeId);
                if (!proceed) return;
            } else {
                stack[stackCount++] = node.leftChild;
                stack[stackCount++] = node.rightChild;
            }
        }
    }
}
```

### 2. 避免自我碰撞与重复碰撞
在 `BroadPhase::UpdatePairs` 中：
*   当物体 A 检索它的邻居时，如果检索到了 A 自己，必须跳过。
*   使用 `std::pair<int32_t, int32_t>` 时，确保 `id1 < id2`，防止 (A, B) 和 (B, A) 重复检测。

### 3. 待处理队列 (Move Buffer)
只有在 `MoveProxy` 返回 `true`（即跳出了肥包围盒）时，才把该物体加入 `m_moveBuffer`。这样如果 1000 个物体里只有 2 个在动，宽相只需要做 2 次查询。

## 5. 今日验收测试 (Unit Test)

1.  **静态查询测试**：
    *   在树中插入 10 个物体。
    *   给定一个覆盖其中 3 个物体的 AABB，调用 `Query`。
    *   **预期**：回调函数被触发且仅触发 3 次，返回正确的物体索引。
2.  **BroadPhase 对过滤测试**：
    *   放置两个相距很远的物体 A 和 B。
    *   将 A 移动到 B 的位置。
    *   调用 `UpdatePairs`。
    *   **预期**：系统能检测到 (A, B) 这一碰撞对。
3.  **性能对比测试 (口头逻辑验证)**：
    *   思考：如果 100 个物体静止，只有 1 个物体在穿梭。
    *   **旧方法 ($O(N^2)$)**：需要检测 $100 \times 100 = 10000$ 次。
    *   **新方法 (BroadPhase)**：只需 1 次 `Query`，检测 $O(\log 100) \approx 7$ 次。
