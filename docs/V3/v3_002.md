胶囊体是现代游戏物理引擎中最重要的几何构件之一（常用于主角 Controller、布娃娃 Ragdoll 的四肢骨骼）。今天我们将完成胶囊体的数据结构定义、物理量推导（面积、质量、转动惯量），并基于**线段几何算法**攻克 `CapsuleVsCircle` 与 `CapsuleVsCapsule` 碰撞流形求解。

## 2. 核心概念

### A. 为什么物理引擎偏爱胶囊体？
相比于带锋利棱角的盒子（Box），胶囊体具有独特的物理优势：
*   **平滑无卡绊**：底部是半圆形，移动时绝不会卡在地表拼接缝隙或台阶边缘上。
*   **计算极其廉价**：数学上，胶囊体本质上是**一条线段的闵可夫斯基和 (Minkowski Sum) 膨胀球**。所有的碰撞都可以退化为“线段与线段的最短距离”检测，无需执行昂贵的多边形 SAT 裁剪。

### B. 几何退化法则：闵可夫斯基和球体 (Swept Sphere)
*   **胶囊体 vs 圆球**：求圆心到胶囊体内部骨架线段的**最近投影点 $P$**。问题瞬间退化为“点 $P$ 处的虚拟圆 vs 目标圆”。
*   **胶囊体 vs 胶囊体**：求两条骨架骨架线段之间的**最近点对 $(P_1, P_2)$**。问题瞬间退化为“点 $P_1$ 的虚拟圆 vs 点 $P_2$ 的虚拟圆”。

```text
       ╭───────╮            ╭───────╮
       │   A   │            │   C   │
       │   │   │            │   │   │
       │   │ P1├────────────┤P2 │   │  <--- 最短线段 P1-P2
       │   │   │            │   │   │
       │   B   │            │   D   │
       ╰───────╯            ╰───────╯
       Capsule 1            Capsule 2
```

## 4. 技术实现细节 (Tips)

### 1. 胶囊体精确转动惯量推导公式
为了让物理旋转完全真实，可以将胶囊体拆为两部分叠加：
1.  **中间矩形**（宽 $2r$，长 $L$）：
    $$m_{rect} = 2rL \cdot \rho$$
    $$I_{rect} = \frac{1}{12} m_{rect} ((2r)^2 + L^2)$$
2.  **两端半圆**（等价于一个半径为 $r$ 的完整圆，但两个半圆质心偏移了 $\pm L/2$）：
    $$m_{cap} = \pi r^2 \cdot \rho$$
    根据平行轴定理，圆盘绕偏移轴的转动惯量约为：
    $$I_{cap} \approx m_{cap} \left( \frac{1}{2} r^2 + \left(\frac{L}{2}\right)^2 \right)$$
3.  **总惯量**：$I_{total} = I_{rect} + I_{cap}$，总质量 $m_{total} = m_{rect} + m_{cap}$。

### 2. 两线段最短距离的 Clamp 夹紧法 (Christer Ericson 经典算法)
设线段 1 为 $P(s) = A + s \cdot u \, (s \in [0, 1])$，线段 2 为 $Q(t) = C + t \cdot v \, (t \in [0, 1])$。
求解点积方程确定未夹紧的参数 $s, t$：
*   **平行线段防御**：当分母（行列式值）小于 `EPSILON` 时说明两线段平行，将 $s$ 锁在 $0.5$ 或端点，防止除以零崩溃。
*   **区域裁剪**：将 $s, t$ 分别裁剪到 $[0, 1]$ 范围内，计算最近距离向量 $\vec{d} = Q(t) - P(s)$。

### 💡 核心代码框架预览 (Capsule.h)

```cpp
#pragma once

#include "physics/Collision/Shapes/Shape.h"

namespace Physics2D {

class Capsule : public Shape {
public:
    // radius: 半径; length: 内部线段长度 (两半圆中心距离)
    Capsule(float radius, float length, const Material& mat = Material())
        : Shape(Type::Capsule), m_radius(radius), m_length(length) {
        this->material = mat;
    }

    virtual ~Capsule() = default;

    AABB ComputeAABB(const Vector2& pos, float angle) const override;
    float GetArea() const override;
    MassData ComputeMass(float density) const override;
    void UpdateMassData() override;

    bool RayCast(RayCastOutput* output, const RayCastInput& input,
                 const Vector2& position, float rotation) const override;

    float GetSweepRadius() const override {
        return m_length * 0.5f + m_radius;
    }

    // 获取局部骨架端点 (默认沿 Y 轴分布)
    Vector2 GetLocalSegmentA() const { return Vector2(0.0f, -m_length * 0.5f); }
    Vector2 GetLocalSegmentB() const { return Vector2(0.0f,  m_length * 0.5f); }

    float GetRadius() const { return m_radius; }
    float GetLength() const { return m_length; }

private:
    float m_radius;
    float m_length;
};

} // namespace Physics2D
```
