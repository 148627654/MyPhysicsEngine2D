# V3-Day 3: 通用凸多边形 (Convex Polygon) 表示与格林惯量积分

## 1. 目标
迈向复杂刚体几何的最关键一步：**实现通用凸多边形碰撞体 (Convex Polygon)**。
在物理引擎中，多边形不能仅仅是一组随意的点集。今天我们将完成多边形的**凸性与逆时针（CCW）绕序校验**、预计算**局部边缘外法线**，并使用基于格林公式（Green's Theorem）的**三角剖分法**精确计算任意凸多边形的**面积、质心偏移量与转动惯量**。

---

## 2. 核心概念

### A. 顶点合法性：凸性与逆时针绕序 (CCW Winding)
为了让后续的分离轴定理（SAT）与流形裁剪生效，多边形必须满足以下几何约束：
*   **严格凸多边形**：多边形内部任意两点的连线必须仍在多边形内部，无内凹角（所有内角 $< 180^\circ$）。
*   **逆时针排列（Counter-Clockwise, CCW）**：顶点必须严格按逆时针顺序存储。根据二维叉积右手法则，沿边缘前进时，多边形内部始终位于前进方向的**左侧**：
    $$(P_{i+1} - P_i) \times (P_{i+2} - P_{i+1}) > 0$$
*   **外法线预计算**：逆时针排序后，边向量 $\vec{e} = (dx, dy)$ 的单位外法线可直接确定为 $(dy, -dx) / \|\vec{e}\|$。

### B. 物理引擎铁律：局部坐标系原点对齐质心 (Centroid Centering)
用户传入的顶点集往往其几何中心不在局部原点 $(0, 0)$。
**如果局部原点不等于质心，施加外力时会导致角加速度出现伪力矩！**
*   **今日攻坚**：必须先计算多边形的真实质心 $C$。
*   **原点修正**：将所有局部顶点统一平移 $P'_i = P_i - C$，强制让局部原点 $(0, 0)$ 成为质心，并将 $C$ 反向补偿到刚体的世界坐标 `body->position`。

### C. 格林公式与多边形惯量积分 (Green's Theorem)
任意多边形都可以以局部原点为基准，拆分成由边 $(P_i, P_{i+1})$ 与原点构成的若干个**带符号的有向三角形（Signed Triangles）**。
通过累加有向三角形的面积、质心和转动惯量，即可实现对任意凸多边形的精确解析积分，彻底告别数值采样估算。

```text
               P2
              /  \
             /    \
            /  O   \  <--- 以原点 O 将多边形剖分为有向三角形 △(O, Pi, Pi+1)
           / (0,0)  \
          P1────────P3
```

## 3. 必须实现的功能清单

    *   `std::vector<Vector2> m_normals`: 对应的边缘单位外法线列表。
    *   `int m_count`: 顶点数量（$\ge 3$）。
- [ ] 实现顶点初始化与合法性校验：
    *   `Set(const Vector2* vertices, int count)`：输入点集，自动进行凸性检查与 CCW 绕序检查。
    *   计算质心并进行**质心归零平移**。
- [ ] 重写 `Shape` 纯虚函数：
    *   `ComputeAABB(pos, angle)`：将所有顶点变换到世界空间取 $\min$ 和 $\max$。
    *   `GetSweepRadius()`：所有局部顶点到原点的最大欧氏距离。
    *   `GetArea()`、`ComputeMass(density)` 与 `UpdateMassData()`。
    *   `RayCast(...)`：基于 Cyrus-Beck / 半空间裁剪算法求解多边形射线相交。

### B. 格林公式积分数学实现
- [ ] **有向面积累加**：
    $$Area = \frac{1}{2} \sum_{i=0}^{n-1} (P_i \times P_{i+1})$$
- [ ] **质心求解**：
    $$C = \frac{1}{6 \cdot Area} \sum_{i=0}^{n-1} (P_i + P_{i+1}) (P_i \times P_{i+1})$$
- [ ] **转动惯量（Moment of Inertia）积分**：
    对每个三角形子项积分累加，利用密度 $\rho$ 求解：
    $$I = \rho \sum_{i=0}^{n-1} I_{\Delta_i}$$

## 4. 技术实现细节 (Tips)

### 1. 三角形转动惯量解析公式
对于以原点 $(0,0)$ 与两顶点 $P_i, P_{i+1}$ 构成的三角形，其对原点的极转动惯量可以直接用以下解析式计算（免除复杂的二重积分）：
$$\text{cross} = P_i.x \cdot P_{i+1}.y - P_i.y \cdot P_{i+1}.x$$
$$I_{\text{sub}} = \frac{1}{12} \cdot \text{cross} \cdot (P_i \cdot P_i + P_i \cdot P_{i+1} + P_{i+1} \cdot P_{i+1})$$
将所有三角形的 $I_{\text{sub}}$ 累加后乘以材质密度 $\rho$，即得到精确的总转动惯量：
$$I_{\text{total}} = \rho \cdot \sum I_{\text{sub}}$$

### 2. 逆时针与外法线推导
对于两相邻顶点 $P_i$ 到 $P_{i+1}$，其边向量为 $\vec{e} = P_{i+1} - P_i$。
在逆时针顶点序下，垂直向外且长度为 1 的法线公式为：
$$\mathbf{n}_i = \frac{(\vec{e}.y, -\vec{e}.x)}{\|\vec{e}\|}$$

### 3. 多边形射线检测 (Cyrus-Beck 算法)
多边形本质上是若干半空间的交集。
1. 对每条边计算射线与边缘直线的交点参数 $t$。
2. 将边区分为“入边（Entering Edge）”和“出边（Exiting Edge）”。
3. 维护有效区间 $[t_{\text{in}}, t_{\text{out}}]$，当 $t_{\text{in}} > t_{\text{out}}$ 时判定为未命中。

## 5. 今日验收测试 (Unit Test)

1.  **Box 与 Polygon 的等价性对照测试（大杀器！）**：
    *   创建一个宽高为 $(2, 4)$、密度为 $1.5$ 的 `Box`。
    *   手动将 4 个矩形角点传入并构造一个 `Polygon`。
    *   **断言**：
        *   `Polygon` 的面积与 `Box` 相同（严格等于 $8.0$）。
        *   `Polygon` 计算出的质心必须为 $(0, 0)$。
        *   `Polygon` 的 `ComputeMass()` 输出的质量与转动惯量，与 `Box` 的理论值误差必须 $< 10^{-5}$！
2.  **质心平移修正测试**：
    *   输入一个偏心三角形：$(10, 0), (13, 0), (10, 4)$。
    *   调用 `Set()` 后，检查内部顶点是否已被平移，使得 $\sum P'_i \times \dots$ 算出的质心归零。
3.  **凸性与逆时针报错拦截**：
    *   输入顺时针顶点集或凹四边形（“飞镖”形），断言系统触发 `assert` 或返回 `false`。
4.  **多边形射线投射测试**：
    *   射线从外部发射击中正五边形侧面，断言命中比例 $t$ 正确且法线精准垂直于被击中边缘。

### 💡 核心代码框架预览 (Polygon.h)

```cpp
#pragma once

#include "physics/Collision/Shapes/Shape.h"
#include <vector>

namespace Physics2D {

class Polygon : public Shape {
public:
    static constexpr int MAX_VERTICES = 8; // 工业界通常限制凸多边形顶点数 <= 8 以换取极致缓存与计算性能

    Polygon(const Material& mat = Material()) 
        : Shape(Type::Polygon), m_count(0) {
        this->material = mat;
    }

    // 核心初始化接口：输入点集，自动进行逆时针排序校验、计算质心并归零化顶点
    bool Set(const Vector2* vertices, int count);

    // 便捷工厂方法：生成正多边形或矩形多边形
    void SetAsBox(float hx, float hy);

    AABB ComputeAABB(const Vector2& pos, float angle) const override;
    float GetArea() const override { return m_area; }
    MassData ComputeMass(float density) const override;
    void UpdateMassData() override;

    bool RayCast(RayCastOutput* output, const RayCastInput& input,
                 const Vector2& position, float rotation) const override;

    float GetSweepRadius() const override { return m_radius; }

    int GetVertexCount() const { return m_count; }
    const Vector2& GetVertex(int index) const { return m_vertices[index]; }
    const Vector2& GetNormal(int index) const { return m_normals[index]; }

private:
    Vector2 m_vertices[MAX_VERTICES];
    Vector2 m_normals[MAX_VERTICES];
    int m_count;
    float m_radius = 0.0f; // 扫掠半径 (用于宽相与CCD)
    float m_area = 0.0f;   // 缓存解析面积
};

} // namespace Physics2D
```
