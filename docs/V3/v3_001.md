# V3-Day 1: 材质系统 (Material) 与 触发器 (Trigger) 架构

## 1. 目标
开启 V3 功能特性的第一步：**解耦物理属性与几何形状**。今天我们将实现通用的 `Material`（物理材质）系统与 `isTrigger`（触发器/传感器）机制。这不仅能让刚体具备更贴近现实的弹性与摩擦特性，也为后续的事件系统（Event System）和多材质碰撞打下数据基础。

---

## 2. 核心概念

### A. 几何与材质解耦 (Geometry vs. Physics Material)
在 V1 中，刚体的摩擦系数和弹性可能被硬编码在 `Body` 或全局参数中。在工业级引擎（如 Unity、Box2D）中，**形状决定“撞不撞”，而材质决定“怎么撞”**：
*   **密度 ($\rho$)**：结合形状面积自动推导刚体的质量（$m$）与转动惯量（$I$）。
*   **恢复系数 ($e \in [0, 1]$)**：决定碰撞是完全非弹性碰撞（$e=0$ 粘在一起）还是完全弹性碰撞（$e=1$ 动能守恒）。
*   **静摩擦与动摩擦系数 ($\mu_s \ge \mu_d \ge 0$)**：分别控制阻止静止物体滑动的阈值与滑动中的阻力。

### B. 材质混合策略 (Combine Modes)
当两个材质完全不同的物体撞击（例如“冰块”撞击“橡胶”）时，应该采用哪一方的参数？
引擎必须具备明确的参数仲裁（混合）规则：
*   **Average（算术平均）**：$\frac{a + b}{2}$
*   **Minimum（最小值优先）**：$\min(a, b)$，常用于冰面滑行（低摩擦主导）。
*   **Maximum（最大值优先）**：$\max(a, b)$，常用于高弹性蹦床（高弹性主导）。
*   **Multiply / Geometric（相乘或几何平均）**：$\sqrt{a \cdot b}$ 或 $a \cdot b$，符合经典库仑摩擦实验规律。

### C. 触发器机制 (Trigger / Sensor)
游戏开发中大量的碰撞检测并不需要物理阻挡（如拾取金币、水域减速区、进入检查点）。
*   **普通 Collider**：参与窄相碰撞、计算 Manifold、产生冲量推开物体。
*   **Trigger (Sensor)**：参与碰撞检测以触发判定，但**完全跳过冲量解算阶段**，物体会像空气一样穿过它，但保留相交数据供后续事件系统派发。

## 3. 必须实现的功能清单

### A. 实现材质与混合规则 (`Material.h`)
- [x] 定义材质属性：
    *   `float density`: 密度（默认 $1.0 \, \text{g/cm}^2$ 或对应 SI 单位）。
    *   `float restitution`: 弹性系数，严格裁剪在 $[0.0, 1.0]$。
    *   `float staticFriction`: 静摩擦系数（$\ge 0.0$）。
    *   `float dynamicFriction`: 动摩擦系数（$\ge 0.0$ 且 $\le \text{staticFriction}$）。
- [x] 实现混合模式枚举与混合计算函数：
    *   `enum class CombineMode { Average, Minimum, Multiply, Maximum }`
    *   `static float Combine(float valA, float valB, CombineMode mode)`
    *   `static Material Combine(const Material& a, const Material& b)`

### B. 重构 `Shape` 基类以支持材质与触发器
- [ ] 为 `Shape`（或 `Collider`）添加成员：
    *   `Material material`: 材质配置。
    *   `bool isTrigger`: 是否为触发器（默认为 `false`）。
- [ ] 在 `Shape` 中增加质量推导接口：
    *   `virtual void UpdateMassData() = 0;`：利用自身面积 $\times$ `material.density` 重新刷新所附着刚体的 `mass` 与 `inertia`。

### C. 解算器旁路改造 (Solver Bypass)
- [ ] 在 `Manifold` 或碰撞响应前增加阻断：
    *   如果参与碰撞的 `ShapeA->isTrigger || ShapeB->isTrigger`，则将流形标记为 `isSensor = true`。
    *   在 `ContactSolver`（冲量解算）中直接 `continue` 跳过此类流形，使其不产生法向与切向冲量。

## 4. 技术实现细节 (Tips)

### 1. 摩擦力物理常识校验
在给材质赋值时，应增加边界防御代码（Clamp），避免物理发散：
```cpp
void Material::Sanitize() {
    restitution = std::max(0.0f, std::min(1.0f, restitution));
    staticFriction = std::max(0.0f, staticFriction);
    dynamicFriction = std::max(0.0f, std::min(staticFriction, dynamicFriction));
    density = std::max(0.0001f, density); // 密度不可为0或负数
}
```

### 2. 混合模式的合理默认值
根据行业共识（如 PhysX/Box2D）：
*   **摩擦力混合**：推荐默认使用 **Multiply**（即 $\sqrt{\mu_1 \cdot \mu_2}$），因为光滑的冰面遇到任何粗糙表面时，整体接触面摩擦都会急剧下降。
*   **弹性恢复混合**：推荐默认使用 **Maximum**（即 $\max(e_1, e_2)$），让弹性极佳的网球无论砸在什么地面上都能弹起。

## 5. 今日验收测试 (Unit Test)

1.  **材质混合数值测试**：
    *   材质 A（弹性 0.2，摩擦 0.8），材质 B（弹性 0.9，摩擦 0.2）。
    *   使用 Maximum 混合弹性，验证结果等于 0.9。
    *   使用 Multiply 混合摩擦，验证结果等于 $\sqrt{0.8 \times 0.2} = 0.4$。
2.  **质量自动重算测试**：
    *   创建一个半径为 $1$ 的圆，当密度设为 $1.0$ 时，质量约为 $\pi \times 1^2 \approx 3.1416$。
    *   将密度动态改为 $2.0$ 并调用 `UpdateMassData()`，断言质量翻倍。
3.  **触发器非阻挡测试**：
    *   小球 A 以 $(10, 0)$ 的速度射向小球 B（B 标记为 `isTrigger = true`）。
    *   模拟 10 步积分（通过碰撞检测但解算跳过）。
    *   **断言**：A 与 B 的 AABB 发生重叠，但 A 的速度始终保持 $(10, 0)$，证明未受到任何法向冲量阻碍。

### 💡 核心代码框架预览 (Material.h)

```cpp
#pragma once
#include <algorithm>
#include <cmath>

namespace Physics2D {

enum class CombineMode {
    Average,   // (A + B) / 2
    Minimum,   // min(A, B)
    Multiply,  // sqrt(A * B)
    Maximum    // max(A, B)
};

struct Material {
    float density = 1.0f;          // 密度
    float restitution = 0.0f;      // 恢复系数 [0, 1]
    float staticFriction = 0.5f;   // 静摩擦系数
    float dynamicFriction = 0.3f;  // 动摩擦系数
    
    CombineMode frictionCombine = CombineMode::Multiply;
    CombineMode restitutionCombine = CombineMode::Maximum;

    Material() = default;
    Material(float d, float r, float sf, float df)
        : density(d), restitution(r), staticFriction(sf), dynamicFriction(df) {}

    static float CombineValues(float a, float b, CombineMode mode) {
        switch (mode) {
            case CombineMode::Average:  return 0.5f * (a + b);
            case CombineMode::Minimum:  return std::min(a, b);
            case CombineMode::Multiply: return std::sqrt(a * b);
            case CombineMode::Maximum:  return std::max(a, b);
            default: return a;
        }
    }
};

} // namespace Physics2D
```
